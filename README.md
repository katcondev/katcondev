## `> whoami`

I'm a **full stack engineer and cloud architect** and I care a lot about building things that actually work well *and* look good doing it. Engineering and design shouldn't be separate conversations.

Right now I'm tech lead and architect on **J-SOS**, an iOS safety app for journalists working in hostile conditions. I own the architecture end to end: the SwiftUI client, the AWS backend, and a security model where the server only ever sees ciphertext.

I'm also running applied AI research with **Anti-Racist AI Futures**, evaluating LLM auto-tagging and image-generation model behavior across a 20,000-image photojournalism archive.

And I run [**FloStack Studio**](https://flostackstudio.com), a digital media studio doing photography, brand design, and custom web builds.

```text
🔭  Building    →  J-SOS, an encrypted iOS safety app for journalists
🔐  Thinking    →  threat models, key management, what a server should never know
🎨  Designing   →  interfaces that work one-handed, under stress, in low light
🧠  Exploring   →  swift, libsignal, offline-first architecture
🌱  Learning    →  always

```
