## `> whoami`

I'm a **full stack engineer and UI/UX designer** and I care a lot about building things that actually work well *and* look good doing it. Engineering and design shouldn't be separate conversations.

Right now I'm tech lead on **J-SOS**, an iOS safety app for journalists working in hostile conditions. I own the architecture, the full SwiftUI client, and the AWS backend behind it.

I also run [**Flo Stack Studio**](https://flostackstudio.com), a digital media studio doing photography, brand design, and custom web builds for clients worldwide.
